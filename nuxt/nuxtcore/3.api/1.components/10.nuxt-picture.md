`<NuxtPicture>` là một thay thế drop-in cho thẻ `<picture>` native.

Usage của `<NuxtPicture>` gần như giống hệt [`<NuxtImg>`](/docs/api/components/nuxt-img) nhưng nó cũng cho phép serving modern formats như `webp` khi possible.

Tìm hiểu thêm về [`<picture>` tag on MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/picture).

## Setup

Để sử dụng `<NuxtPicture>` bạn nên install và enable Nuxt Image module:

```bash [Terminal]
npx nuxt module add image
```
