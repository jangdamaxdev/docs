---
title: Vite
description: 'Activate Vite to your Nuxt 2 application with Nuxt Bridge.'
---

::warning
Khi sử dụng `vite`, [nitro](/docs/bridge/nitro) phải đã được cấu hình.
::

## Remove Modules

- Xóa `nuxt-vite`: Bridge kích hoạt cùng chức năng

## Update Config

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    vite: true,
    nitro: true
  }
})
```

## Configuration

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  vite: {
    // Config for Vite
  }
})
```
